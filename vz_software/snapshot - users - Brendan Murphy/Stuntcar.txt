STUNT CAR RACER - VZ300 version.  v1.1	Brendan murphy. Oct 2026
===============================

Original game (C) Geoff Crammond 1988/9; ZX Spectrum version by Pete Cooke.
This is a conversion of the ZX Spectrum game to the Dick Smith VZ300. The
original Spectrum game code (physics, tracks, opponents, rules, menus) runs
unchanged; only the screen, sound, keyboard and joystick routines are new.
Needs: VZ300, BennVenn 128K RAM expansion, BennVenn SD loader.
File: STUNTCAR.VZ (30,500 bytes) - load and run it from the SD loader.


Controls (keyboard)
S accelerate X brake / reverse
O steer left P steer right
M or SPACE fire (boost while accelerating, select in menus)
SHIFT+SPACE pause: then Q = quit race, S = sound on/off, RETURN = resume
Joystick 1 or 2 work as well (up = accelerate, down = brake, fire = boost).
Notes
Load/Save: there is no tape. Save keeps the season in memory and Load
brings it back, for as long as the VZ stays switched on.
Memory use
$4000-$67FF DOS RAM bank 0: renderer, buffers, lookup tables (built at
start-up), screen back buffer at $5B00
$4000-$67FF DOS RAM bank 1: start-up, title screen and music, menus, text
$7000-$77FF video RAM
$7800-$B7FF internal RAM: original game
$B800-$FFFF expansion bank 0: original game (with VZ driver code in the
spaces left by replaced Spectrum routines)
$B800-$FFFF expansion bank 1: bonnet art and boost flame graphics
The file is compressed (ZX0); the loader unpacks it into the banks above.
