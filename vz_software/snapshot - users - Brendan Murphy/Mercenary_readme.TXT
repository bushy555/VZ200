Mercenary: Escape from Targ .    (Brendan Murphy)

Tested on VZ300. Supports VZ joystick. 

Requires BennVenn 128kb RAM expansion (though I am loading from SVI-CAS). 
Crashes in VZEM.

Movement
5 - turn left
8 - turn right
7 - forward (dive when flying)
6 - back (climb when flying)
0 - fire

Speed
1, 2, 3, 4 - forward speed (1 slowest)
CTRL + 1 to 4 - reverse thrust (flying)
SPACE - brake (hover when flying)

Actions
E - elevator
T - take object
D - drop object
B - board vehicle
L - leave vehicle
Y - yes

Game control
SHIFT + RETURN - pause
RETURN - resume
SHIFT + Q - escape a tight spot
SHIFT + S - save (avoid: hangs)
SHIFT + L - load (avoid: hangs)
