All 2026 release games & demos, mostly from the current AI craze.

Most will require the Benn Venn SD Loader with joysticks plugged in. The SD Loader can supply 10k of extra ram from $4000 to $6800 along with 32k from $8000 to $ffff, and then another bunch of switchable 16kb banks from $c000 to $ffff.  Using compression its possible to now do some crazy stuff that was never before able.  A few of these games will work without the loader.

Majority are by Brenden M, See : https://github.com/imbrendenmurphy-dev/VZ300-and-MIcrobee-games/ for his original source, binaries and release notes. Along with a few other enthusiasts over on the Laser/VZ Facebook group : https://www.facebook.com/groups/4609469943
