Flash to your Tang Nano 9k
Z80 core, 16kbytes VZ basic rom, 2kbytes VRAM, 16kbytes system ram, a very primitive character generator using the VZ's CHR ROM, 640x480 HDMI output (not scaled yet, so it's 256x128 pixels out of a 640x480 window)
No other VDP modes coded yet, no keyboard IO or anything like that.
26% of FPGA resources consumed. A full VZ implementation should easily fit the 9k gowin FPGA.
